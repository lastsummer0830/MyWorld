### 4면도에서 읽은 실패 원인 (다시 하지 않을 것)
1. 긴 튜브 목 위에 작은 머리 → 라마/사슴 실루엣.
2. 두개골 높이의 1/4에 달하는 **뿔 귀**(0.237H)와 갈색 두개골 얼룩.
3. 가슴 앞에 매단 **갈기 베개** — 갈기가 별도 loft라 몸과 경계가 생겼다.
4. 관절 없는 원뿔 다리, 엉덩이에서 떨어져 나온 갈고리 꼬리.
5. 정점 색 보간 → 무늬 경계가 번지고, 그걸 막으려 등분수를 낮추자 각면이 무늬를 삼켰다.

## 설계

기준 **H = 코트 포함 기갑 높이 = 1.0**, 바닥 y = 0, 강아지는 +x를 보고 **왼쪽이 −z**(기존 규약).

| 항목 | 목표 | 구현값(계산 기준) |
| --- | --- | --- |
| 머리 길이 | 0.435H | 0.429H (후두 x 0.393 → 코끝 0.822) |
| 두개골 폭 | 0.245H | 0.243H (side 0.116 + 볼털 채널) |
| 두개골 : 주둥이 | 1 : 1.02 | 0.212 : 0.217 = 1 : 1.024 (스톱 x 0.605) |
| 귀 높이 / 밑변 | 0.14H / 0.078H | 0.136H / 0.078H, 두께 0.026H, 끝 0.042H 전방 접힘 |
| 귀 간격 | 확실히 분리 | 밑변 중심 ±0.076, 안쪽 모서리 간격 0.074 |
| 몸통 길이 | 1.17H | 어깨끝~좌골 1.15H (코트 자락 포함 시 1.27H) |

**몸통은 껍데기 하나다.** 코 → 주둥이 → 두개골 → 환추/목 → 전흉 → 몸통 → 엉덩이/꼬리 밑동이
단면 26개를 이은 단일 loft다. 목·머리를 따로 만들지 않으므로 "목이 튜브로 남는" 실패가 구조적으로 불가능하다.

**갈기·펜츠·페더링은 메시가 아니다.** 세계 방향 로브 16개(`loft.ts`의 coat 채널)로 몸통 표면 반경을
부풀린 authored 필드다. 매달 메시가 없으니 베개가 생길 자리도 없다.

**다리**는 어깨/엉덩이 덩어리 → 위팔/허벅지 → 팔꿈치/무릎 → 아래팔/비절 → 계부 → 발까지
단면 16개로 꺾이고, 첫 두 단면이 몸통 **안쪽**에서 시작한다(관절 좌표를 맞추는 대신 겹쳐서 붙인다).
네 발 모두 바닥 접촉면이 y = 0.000이고 발끝이 앞으로 뻗어 발가락 세 개가 실루엣에 남는다.

**꼬리**는 엉덩이 안(x −0.640, y 0.830)에서 시작해 낮게 흐르고, 깃은 plume 채널이 만든다.

## 색이 번지지 않는 방법

`loft()`는 non-indexed로 사각형을 굽되 **사각형 하나에 색 하나**를 넣고, 법선은 격자 중앙차분으로
따로 계산해 **연속(smooth)** 으로 유지한다. 그래서

- 무늬 경계가 정점 보간으로 번지지 않고,
- 그러면서도 표면 음영은 각면으로 부서지지 않으며,
- 무늬가 표면 좌표(진행 u, 단면각 a)에서 정의되므로 등을 타고 옆구리로 **휘어 넘어간다.**

멀 얼룩은 이름 붙은 여덟 개의 표(`dogMarkings.ts`)다. 난수가 아니고, 경계는 타원을
authored 코사인 두 개로 흔든 것이라 직사각형이 아니다. 얼룩 둘레의 중간톤 헤일로가 멀의 얼룩덜룩함을 만든다.

황갈(탄)은 **눈썹·볼·아랫옆구리 띠·뒷다리 비절 앞**에만 있다. 두개골 갈색 얼룩은 없다.
